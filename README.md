# RenovateAM

Платформа предварительной онлайн-оценки стоимости ремонта. Клиент получает ориентировочную цену за минуту, не дожидаясь выезда замерщика; компания не тратит выезд и часы сметчика на клиентов, которые откажутся из-за бюджета.

**Рынок:** Армения. **Языки:** русский, армянский, английский. **Валюта:** AMD (драм).

---

## Проблема

Текущая воронка расходует самый дорогой ресурс компании — выезд и работу сметчика — на клиентов, чей бюджет никто не проверил заранее. Отказ происходит в самом конце, после того как обе дорогие затраты уже понесены.

RenovateAM переносит точку отказа в начало воронки: клиент видит ориентир по цене до того, как к заявке прикоснётся человек.

## Решение: двухуровневая оценка

| Уровень | Кто считает | Когда | Результат |
|---|---|---|---|
| 1 — Быстрый расчёт | Автоматически | Мгновенно, без регистрации | Вилка «от — до» по стандартному пакету |
| 2 — Ручное рассмотрение | Сметчик | 1–2 рабочих дня | Детальная смета по позициям |

Автоматический расчёт работает **только для стандартного пакета отделки**. Любые дизайнерские решения уходят в ручное рассмотрение — цена там зависит от сложности работ и не поддаётся формуле.

---

## Ценовая модель

**База: 60 000 AMD за 1 м²** — стандартный пакет, ремонт под ключ, квартира, без дизайнерских решений.

```
Оценка = Площадь (м²) × 60 000 AMD × Кобъём × Кобъект × Ксостояние × Кпотолки
Вилка  = Оценка × 0.85  …  Оценка × 1.15
```

| Коэффициент | Значения | Множитель |
|---|---|---|
| `Кобъём` | Под ключ / Чистовая / Черновая | 1.00 / 0.60 / 0.45 |
| `Кобъект` | Квартира / Частный дом | 1.00 / 1.15 |
| `Ксостояние` | Новостройка / Вторичка с демонтажом | 1.00 / 1.15 |
| `Кпотолки` | до 3 м / от 3 м | 1.00 / 1.10 |

> Все множители, кроме базовой ставки, — предварительные. Подлежат калибровке сметчиком на 20–30 закрытых проектах до запуска. Базовая ставка и коэффициенты хранятся в БД с версионированием и меняются через админку без релиза.

**Пример.** Квартира 80 м², под ключ, стандартный пакет, новостройка, потолки 2.8 м:
`80 × 60 000 × 1.0 × 1.0 × 1.0 × 1.0 = 4 800 000 AMD` → вилка **4 080 000 — 5 520 000 AMD**.

**Правило маршрутизации.** Если выбран не стандартный пакет — автоматический расчёт не выполняется. Клиент видит сообщение: «Ваш проект требует индивидуального расчёта — сметчик подготовит смету в течение 2 рабочих дней» и переходит к загрузке файлов. Ожидаемое распределение: 60–70% заявок идут по автоматическому пути.

## Архитектура

Два развёрнутых компонента, чёткая граница по HTTP API.

```
┌──────────────────────┐        ┌──────────────────────┐
│  Frontend (Netlify)  │ ─────► │   API (Railway)      │
│  React + Vite + TS   │  REST  │   NestJS + Prisma    │
│  i18n: ru / hy / en  │        │   JWT-аутентификация │
└──────────────────────┘        └──────────┬───────────┘
                                           │
                    ┌──────────────────────┼──────────────────────┐
                    ▼                      ▼                      ▼
            ┌───────────────┐    ┌──────────────────┐   ┌──────────────────┐
            │  PostgreSQL   │    │  S3 (Cloudflare  │   │  Resend (email)  │
            │   (Neon)      │    │  R2), подписанные│   │  WhatsApp API    │
            └───────────────┘    │  ссылки          │   └──────────────────┘
                                 └──────────────────┘
```

API разделён на изолированные доменные модули с собственными контрактами:

| Модуль | Ответственность |
|---|---|
| `auth` | Регистрация, вход, верификация e-mail, JWT |
| `pricing` | Ставки, коэффициенты, версионирование, движок расчёта |
| `requests` | Заявки, статусы, маршрутизация на ручное рассмотрение |
| `files` | Загрузка БТИ и дизайн-проектов, подписанные ссылки |
| `notifications` | E-mail и WhatsApp-уведомления |
| `admin` | Очередь сметчика, загрузка смет, редактор ставок |

Модули не обращаются к чужим таблицам напрямую — только через публичный интерфейс модуля. Это позволяет вынести любой из них в отдельный сервис без переписывания вызывающего кода.

## Стек

**Frontend:** React 18, Vite, TypeScript, TailwindCSS, react-hook-form + zod, react-i18next, TanStack Query
**Backend:** NestJS, TypeScript, Prisma, PostgreSQL, JWT + refresh, class-validator
**Инфраструктура:** Netlify (фронт), Railway (API), Neon (БД), Cloudflare R2 (файлы), Resend (почта)
**Качество:** Vitest, Playwright, ESLint, Prettier, Husky

---

## Структура репозитория

```
RenovateAM/
├── apps/
│   ├── web/                 # React SPA → Netlify
│   └── api/                 # NestJS API → Railway
│       └── src/modules/     # auth · pricing · requests · files · notifications · admin
├── packages/
│   ├── shared-types/        # общие DTO и типы
│   └── pricing-core/        # чистая функция расчёта, переиспользуется фронтом и API
├── docs/
│   ├── MVP.md               # объём MVP, критерии приёмки
│   └── ARCHITECTURE.md
└── README.md
```

`pricing-core` — отдельный пакет намеренно: одна и та же логика расчёта работает на клиенте (мгновенный отклик) и на сервере (источник истины). Реализация одна, расхождений быть не может.

## Локальный запуск

```bash
pnpm install

cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env

pnpm --filter api prisma migrate dev
pnpm --filter api prisma db seed      # базовая ставка 60 000 AMD и коэффициенты

pnpm dev                               # web :5173 · api :3000
```

### Переменные окружения

**API**

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Строка подключения PostgreSQL |
| `JWT_SECRET` / `JWT_REFRESH_SECRET` | Подпись токенов |
| `S3_ENDPOINT` / `S3_BUCKET` / `S3_ACCESS_KEY` / `S3_SECRET_KEY` | Хранилище файлов |
| `RESEND_API_KEY` | Отправка писем |
| `APP_URL` | Базовый URL фронта для ссылок верификации |

**Web**

| Переменная | Назначение |
|---|---|
| `VITE_API_URL` | Адрес API |
